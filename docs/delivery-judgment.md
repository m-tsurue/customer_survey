# 納車後アンケート 判定ロジック

2026年9月24日取得の [コード.gs](../delivery/コード.gs) に基づきます。

| 項目 | 対象の設問 | 判定ルール |
|---|---|---|
| 納車全体の印象 | ① 納車されたお車の状態に、ご満足いただけましたか？<br>② 納車当日の対応（ご説明、書類のお渡し、お車の受け渡し時間など）は、スムーズでしたか？<br>③ ご契約から納車までの全体の流れについて、ご満足いただけましたか？ | 強い不満が1つ以上、または軽い不満が2つ以上 → 🔴ネガティブ・要フォロー<br>軽い不満が1つ → 🟡ややネガティブ・要確認<br>どちらもなし → 🟢問題なし<br>全問未回答 → 未回答 |
| 自由記入欄 | ① お車の状態について、具体的にどのような点にご不満がございましたか？<br>② 納車対応当日の対応について、具体的にどのような点にご不満がございましたか？<br>③ ご契約から納車までの流れについて、具体的にどのような点にご不満がございましたか？<br>④ その他、お気づきの点や今後BUDDICAに期待することなど、お聞かせください。 | いずれかに入力あり → 内容に関係なく「⚠️コメントあり、必ず確認」<br>すべて入力なし → コメントなし |
| DIRECT体験 | ① オンラインでご覧になった写真や動画と、実際のお車の印象にギャップはありましたか？<br>② 次回も、今回のようにオンライン（非対面）サービスを利用して車を購入したいと思いますか？ | 「今回、車のオンライン通販サービス『BUDDICA DIRECT』を利用されましたか？」への回答が「はい」の場合に判定。<br>強い不満が1つ以上、または軽い不満が2つ以上 → ×ネガティブ<br>軽い不満が1つ → △ややネガティブ<br>どちらもなし → ◯問題なし<br>利用「いいえ」 → 未利用<br>利用未回答 → 未回答 |
| 紹介意向 | 今後、BUDDICAを大切なご友人やご家族、知人に紹介してもよいと思われますか？ | 強くそう思う → 5/5<br>ある程度そう思う → 4/5<br>どちらともいえない → 3/5<br>あまりそう思わない → 2/5<br>全くそう思わない → 1/5<br>未回答 → 未回答<br>納車全体・DIRECT体験の判定には含めない |

| 不満の区分 | 完全一致で判定する回答（前後の空白を除去） |
|---|---|
| 強い不満 | 不満がある／期待より悪かった／大きく期待を下回った／全くしたくない／全くそう思わない |
| 軽い不満 | やや期待と異なっていた／あまりしたくない／あまりそう思わない |

- DIRECT利用「はい」で体験の2問が両方未回答でも「◯問題なし」になります。
- 自由記入の内容分析は行わず、記入の有無のみを判定します。自由記入は納車全体の不満件数に加算しません。
- 紹介意向は上記以外の回答なら、その回答をそのまま表示します。
- 配列回答では不満の回答値ごとに加算します。通常の単一選択の設問では1問につき1回答です。
- 通知のメンション条件は [GAS 設定・復元手順](gas-settings.md#slack通知) を参照してください。
