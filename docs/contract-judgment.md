# 成約後アンケート 判定ロジック

2026年9月24日取得の [コード.gs](../contract/コード.gs) に基づきます。設問冒頭の `Q :` / `Q ` は表では省略しています。実際の照合はコードに記載した設問名との一致です。

| 項目 | 対象の設問 | 判定ルール |
|---|---|---|
| 接客に対する印象 | ① BUDDICAの下取価格について、提示された金額にご納得いただけましたか？<br>② ご提案内容は、お客様のご希望に沿っていましたか？<br>③ 車両やオプションについてのご説明は、分かりやすかったですか？<br>④ 必要書類についてのご説明は、分かりやすかったですか？<br>⑤ 納車までの流れやスケジュールについて、ご理解いただけましたか？<br>⑥ 身だしなみはいかがでしたか？<br>⑦ 言葉遣いはいかがでしたか？<br>⑧ お店は入りやすい雰囲気でしたか？<br>⑨ お店の清掃は行き届いていましたか？<br>※実装上は下記のLINEの2問を除く全回答が対象。 | 強い不満が1つ以上、または軽い不満が2つ以上 → 🔴ネガティブ・要フォロー<br>軽い不満が1つ → 🟡ややネガティブ・要確認<br>どちらもなし → 🟢問題なし |
| 自由記入欄 | その他、お気づきの点や今後BUDDICAに期待することなど、お聞かせください。 | 入力あり → 内容に関係なく「⚠️コメントあり、必ず確認」<br>入力なし → コメントなし |
| 担当者・店舗の印象 | ① 身だしなみはいかがでしたか？<br>② 言葉遣いはいかがでしたか？<br>③ お店は入りやすい雰囲気でしたか？<br>④ お店の清掃は行き届いていましたか？ | 強い不満が1つ以上、または軽い不満が2つ以上 → ×ネガティブ<br>軽い不満が1つ → △ややネガティブ<br>どちらもなし → ◯問題なし<br>全問未回答 → 未回答 |
| ダイレクト印象 | ① LINEでの各種お手続き（契約案内や書類のやり取りなど）は、分かりやすかったですか？<br>② LINEでの担当者からのご返信やご連絡のスピードに、ご満足いただけましたか？ | DIRECT利用「はい」の場合に判定。<br>強い不満が1つ以上、または軽い不満が2つ以上 → ×ネガティブ<br>軽い不満が1つ → △ややネガティブ<br>どちらもなし → ◯問題なし<br>利用「いいえ」 → 未利用<br>利用未回答 → 未回答 |

| 不満の区分 | 完全一致で判定する回答（前後の空白を除去） |
|---|---|
| 強い不満 | 納得できなかった／わかりづらかった／遅いと感じた／分かりづらかった／不明点がある／気になる点があった／入りにくい |
| 軽い不満 | もう少し検討したかった／少しわかりづらかった／少し遅いと感じた／希望と少し違った／少し分かりづらかった／少し不明点がある／少し気になる |

- 担当者・店舗の4問は「接客に対する印象」にも含まれます。表示ごとの集計であり、接客に対する印象の内部で二重加算するわけではありません。
- 「接客に対する印象」は全問未回答でも「🟢問題なし」になります。
- DIRECT利用「はい」でLINEの2問が両方未回答でも「◯問題なし」になります。
- 接客に対する印象はLINEの2問以外を広く走査します。自由記入などの回答全体が上記の不満表現と完全一致した場合にも加算されます。文章の意味や部分一致で判定する処理ではありません。
- 配列回答では不満の回答値ごとに加算します。
- 通知のメンション条件は [GAS 設定・復元手順](gas-settings.md#slack通知) を参照してください。
